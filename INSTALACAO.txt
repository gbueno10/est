🚀 INSTRUÇÕES DE CONFIGURAÇÃO (SETUP) DO PROJETO 📊

Siga os passos abaixo para preparar o ambiente e instalar as dependências necessárias para rodar os notebooks e scripts.

---

1️⃣ CRIAR O AMBIENTE VIRTUAL (VENV)
O ambiente virtual isola as bibliotecas deste projeto das do seu sistema.

No Terminal (macOS/Linux):
   python3 -m venv .venv

No Prompt de Comando/PowerShell (Windows):
   python -m venv .venv

---

2️⃣ ATIVAR O AMBIENTE VIRTUAL
Você deve ativar o ambiente sempre que for trabalhar no projeto.

No Terminal (macOS/Linux):
   source .venv/bin/activate

No Prompt de Comando (Windows):
   .venv\Scripts\activate

No PowerShell (Windows):
   .\venv\Scripts\Activate.ps1

---

3️⃣ INSTALAR AS DEPENDÊNCIAS
Com o venv ativado (aparecerá '(.venv)' no início da linha do terminal), execute:

   pip install --upgrade pip
   pip install -r requirements.txt

---

🛠️ REQUISITOS INSTALADOS:
- NumPy (Cálculos numéricos)
- SciPy (Distribuições estatísticas e testes)
- Matplotlib (Gráficos)
- Seaborn (Estilo visual opcional)

---

📓 PARA USAR NO VS CODE:
1. Abra um arquivo '.py' ou '.ipynb'.
2. Clique no seletor de Kernel (canto superior direito no Notebook).
3. Selecione 'Python Environments...' -> '.venv'.
